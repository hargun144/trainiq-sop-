TrainIQ — SOP to AI Training System

Convert any SOP document into structured, ready-to-use employee training content using AI.  
Built by Hargun Kaur.

---

## 💡 What it does

Paste an SOP → click Generate → instantly get:

📋 Concise module summary  
🎯 Key learning points  
📚 Step-by-step training guide  
❓ 5-question quiz with answers

## ⚙️ Tech Stack

Frontend: HTML, CSS, JavaScript  
Backend: Vercel Serverless Functions  
AI: LLaMA 3 (70B) via Groq API  

---

## 🚀 Why this matters

Training employees using SOPs is typically manual, inconsistent, and time-intensive.

TrainIQ automates this process — converting static SOPs into structured training modules in seconds, enabling faster onboarding, standardized learning, and scalable training workflows.
